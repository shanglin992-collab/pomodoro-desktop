# 在手机上用 Termux 运行番茄钟（保姆级步骤）

> 适用：已经装好 Termux、第一次打开看到黑底白字终端的人。
> 目标：把电脑上 `pomodoro-desktop-main/android/` 里的番茄钟，在手机上以原生 App 形式跑起来。

---

## 一、你眼前看到的是什么（先安心）

打开 Termux 后是一块黑屏，最下面有一行类似：

```
~ $
```

或者带一串字，最后有个 `$` 和闪动的光标。这就是**终端**，接下来所有操作都是在 `$` 后面**打字 + 回车**。

- 手机上**点一下屏幕**会弹出虚拟键盘。
- **长按**终端区域可以「粘贴」你从别处复制的命令。
- 每条命令打完按**回车**才执行。

---

## 二、先把 `android` 文件夹弄到手机上

电脑上的 `pomodoro-desktop-main/android/` 里有这些文件（`main.py`、`timer_core.py`、`requirements.txt`、`assets/icon.png`）——必须让手机也能读到它们。

**方法 A：USB 数据线（最简单）**
1. 手机用数据线连电脑，手机通知栏选「传输文件 / MTP」。
2. 电脑上把 `android` 整个文件夹，复制进手机的「Download（下载）」文件夹。
3. 拔线。

**方法 B：微信 / 网盘中转**
1. 在电脑上把 `android` 文件夹压缩成 zip，通过微信文件传输助手 / 网盘发到手机。
2. 手机上把 zip 解压，得到 `android` 文件夹，放进「Download（下载）」。

> 记住你把它放在手机哪个位置（下面默认放到了 Download）。

---

## 三、在 Termux 里一步步执行

打开 Termux，按顺序复制下面的命令，**一条一条来**，每条回车后等它跑完（出现新的 `$` 再输下一条）。

### 第 1 步：更新软件源
```bash
pkg update
```
> 会刷一串字，最后回到 `$` 就正常。

### 第 2 步：装 Python
```bash
pkg install python -y
```
> `-y` 是自动确认。会下载安装，等它回到 `$`。

### 第 3 步：装图形库（防 kivy 运行时缺组件，建议先装）
```bash
pkg install sdl2 sdl2-image sdl2-ttf sdl2-mixer -y
```

### 第 4 步：装番茄钟依赖（kivy + plyer）
```bash
pip install kivy plyer
```
> ⚠️ 这步最慢，可能要 **5~10 分钟**，会刷很多下载进度条，手机请连 WiFi 并插着电。
> 只要最后回到 `$`、没报红色 `ERROR` 就行。

### 第 5 步：让 Termux 能访问手机存储
```bash
termux-setup-storage
```
> 手机会弹「允许 Termux 访问文件」的授权框，**点允许**。这会在 `~` 下生成 `storage/shared` 指向手机内部存储。

### 第 6 步：把 android 文件夹复制到 Termux 自己的目录
（假设你把 `android` 放在了手机 Download 里）
```bash
cp -r ~/storage/shared/Download/android ~/
```
> 如果你放到了别处，把路径 `Download/android` 改成实际位置，例如 `Download/番茄钟/android`。

### 第 7 步：进入文件夹并启动
```bash
cd ~/android
python main.py
```
> 敲下回车后，**稍等几秒，手机会弹出一个全屏的番茄钟窗口**（进度环 + 开始/暂停等按钮）。这就成功了！

---

## 四、怎么用 / 怎么退出

- **开始计时**：点界面上的「开始」。
- **暂停 / 继续**：「暂停 / 开始」按钮。
- **跳过当前段**：「跳过」。
- **重置**：「重置」。
- **退出程序**：直接按手机「返回键」；或在终端里按 `音量减 + C`（等于 Ctrl+C）强制停止。

---

## 五、常见问题

**Q：运行 `python main.py` 后没弹窗口，只报一堆错？**
- 最常见是 SDL / 显示相关。先确认第 3 步的 sdl2 装了；重跑 `python main.py`。
- 部分手机需要给 Termux 开启「显示悬浮窗 / 在其他应用上层显示」权限：系统设置 → 应用 → Termux → 权限里打开。

**Q：通知 / 震动没反应？**
- 完成一段本应弹通知+震动。要让通知生效，建议在 F-Droid 或应用商店再装一个 **Termux:API** App，并在 Termux 里 `pkg install termux-api`。不装也不影响计时主功能。

**Q：想让番茄钟像普通 App 一样在桌面一键打开？**
- 装 **Termux:Widget**（F-Droid 有），可以把 `python main.py` 做成桌面快捷方式。
- 或走正式安装路线：在电脑 Linux 环境用 `buildozer android debug` 打包成 `.apk`（详见同目录 `README.md`）。

**Q：机器翻译/英文看不懂，终端里字太小？**
- 双指捏合可以缩放 Termux 字体；长按终端 → More → Settings 里也能调字号。
